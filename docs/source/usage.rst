Usage
=====

This section contains the practical IntelliCage Analysis Toolkit workflow
based on the public scripts in the repository's ``user_scripts/`` folder.

The tutorial uses the synthetic Group A/B datasets generated by the repository
itself. The dataset is deliberately small, public, and reproducible, but it
keeps the same table names and folder structure expected from IntelliCage
exports.

We recommend to start with :doc:`usage_prepare_data` and then continue with
:doc:`usage_place_learning_reversal`. Together they walk through the full
analysis path: arranging IntelliCage exports, understanding the experiment
protocol, getting the synthetic dataset, preparing ``Visits.txt`` and
``Nosepokes.txt`` inputs, building a user script step by step, and interpreting
the generated result tables and plots.
